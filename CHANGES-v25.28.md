# CHANGES v25.28 — финальная полировка перед деплоем (TRI999)

Дата: 2026-08-29 · Позиционирование: **TRI999** («Три девятки»)

---

## 1. Ребрендинг 999PRO → TRI999 (везде)
- `src/lib/brand.ts` — единый источник: BRAND_* = «TRI999». Технические ключи
  (localStorage-префикс `999pro-`, npm-имя `@999pro/shared`, логины демо-аккаунтов)
  НЕ тронуты — это невидимые идентификаторы, их смена сломала бы PWA-кэши.
- Заменены все видимые строки: шапки, splash-подпись, лента, профиль, «О компании»,
  поддержка, QR-шеринг, PWA-промпт, onboarding, онбординг-заголовок, share-тексты,
  ical PRODID, Media Session (артист/альбом), SEO/OG/JSON-LD метаданные,
  `public/manifest.webmanifest` (name/short_name), студийные SEO-дефолты.
- Версия приложения: 25.28 (экран «Ещё»), package.json 25.28.0.

## 2. Дизайнерские шрифты (кириллица, «красиво и НЕ крупно»)
- **Onest** — основной текст; **Unbounded** — дисплейная гарнитура бренда
  (логотип TRI999, акценты). Подключены через `next/font/google`
  (subsets: latin+cyrillic), CSS-переменные `--font-onest` / `--font-unbounded`,
  утилита `.font-display` в globals.css. Размеры BrandLogo уменьшены на ступень.

## 3. Игровой клуб
- **«Космический шутер» полностью удалён** (карточка, dynamic import, SVG-превью,
  файл shooter-game.tsx). В клубе теперь 26 игр.

## 4. Чат — редизайн личного диалога (v2, владелец: «чистый премиальный»)
- **Композер**: 4 элемента вместо 6 — `＋` (всплывающее меню), `📎` (файлы),
  капсула поля, градиентная кнопка 🎤/➤ (morph).
- **Всплывающее меню «＋»** (spring, glass, иконки в цветных плитках):
  «Играть» (онлайн-дуэли), «Медиа» (музыка/фильмы), «Товар» (из каталога).
  Кнопка вращается в «×» при открытии; закрытие — клик мимо.
- **Кнопка эмодзи убрана** (эмодзи набираются с клавиатуры) — EmojiPicker
  отключён от композера.
- **Одиночный эмодзи** — крупный (52px) анимированный (spring pop-in), без
  пузыря, как в Telegram. Несколько эмодзи/текст — обычный пузырь.
- **Blur-фейды** вместо белой mask-маски: сообщения растворяются в backdrop-blur
  под шапкой и над полем ввода (iOS/Telegram-стиль).
- **Авторост поля ввода** до 132px при ЛЮБОМ изменении текста (ввод, вставка,
  черновик, правка) — раньше поле не расширялось при программных изменениях.
- **Панель автозаполнения браузера** («стрелки над клавиатурой»), накрывавшая
  поле: `autocomplete=off, autocorrect=off, spellcheck=false,
  data-form-type=other, data-lpignore, enterkeyHint=send`. Полностью убрать
  системную панель браузера нельзя (это ОС/браузер), но перечисленные атрибуты
  убирают её в Chrome/Android и большинстве оболочек.
- Закрепление сообщений (из v25.27) работает: плашка сверху диалога, тап →
  прокрутка, × → открепить, socket-синхронизация.

## 5. Чат — список диалогов: «нет сообщения»
- Причины: превью не получало `attachments` (группы фото/файлов показывались
  как «Нет сообщений»), а сообщение, удалённое «у меня», всё равно было
  последним. Бэкенд: берём 8 последних сообщений и отдаём первое ВИДИМОЕ мне +
  распарсенные attachments; фронт: live-превью тоже носит attachments.

## 6. Игры — контраст в светлой теме («тексты сливаются»)
- Системная замена белых полупрозрачных утилит на темы токены
  (`bg-white/[0.06]`→`var(--g-btn)`, `text-white/80`→`var(--g-fg-soft)` и т.д.)
  в 20 играх (59 замен). «Тёмные миры» (раннеры, танки, дудл) не тронуты — там
  белый текст на тёмных сценах корректен.
- «Миллионер»: заголовки старт/финал → тематический цвет; карточка вопроса —
  тёмно-синяя в обеих темах; нейтральные варианты — стекло темы + тёмный текст.
- «Викторина (quiz-run)»: заголовки старт/вопрос/финал → fg-токен.
- «Тетрис»: пад-кнопки и glass-кнопка звука → fg-токен.

## 7. ТВ и старые браузеры (из v25.27, финализировано)
- `scripts/legacy-css.mjs` — пост-обработка CSS: разворачивает `@layer`
  (Tailwind v4), понижает oklch/color-mix/nesting через lightningcss
  (targets: Chrome 81/Safari 13/Firefox 78). Встроен в `npm run build`
  (frontend + studio).
- `public/legacy-polyfills.js` — globalThis, crypto.randomUUID,
  Resize/IntersectionObserver-заглушки, Element.closest, scroll-опции;
  на браузерах без ES-модулей — вежливая плашка «обновите браузер».
- `browserslist` в package.json; сборка фронтенда переведена на
  `next build --webpack` (Turbopack падал по OOM на хостах 4GB).
- Композер/новые UI сознательно без `color-mix()` — rgba/var-фолбэки.
